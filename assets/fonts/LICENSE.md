# Fonts

Both fonts are the ones the game itself ships (`Assets/Fonts` in the game repo),
licensed under the SIL Open Font License, Version 1.1: https://openfontlicense.org

- `baloo2-latin.woff2`: Baloo 2, Copyright 2019 The Baloo 2 Project Authors
  (https://github.com/EkType/Baloo2). Cut down to Latin characters.
- `lilita-one.woff2`: Lilita One, Copyright (c) 2011 Juan Montoreano
  (juan@remolacha.biz), with Reserved Font Name "Lilita One". Glyphs unmodified;
  only the container was converted from TTF to WOFF2.

The license and copyright records are kept inside each font file's name table.
